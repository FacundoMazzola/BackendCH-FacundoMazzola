# Proyecto Backend - Coderhouse

## Tecnologías utilizadas
- Node.js
- Express
- MongoDB
- Mongoose
- Handlebars
- Socket.io

## Funcionalidades
- CRUD de productos
- Paginación, filtros y ordenamiento
- Carrito de compras
- Vistas dinámicas con Handlebars
- Persistencia en MongoDB

## Cómo ejecutar
```bash
npm install
npm run dev
